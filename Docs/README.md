# Project Documentation Index

이 문서는 프로젝트의 상세 개발 문서를 안내하는 목차입니다.

AI는 작업을 시작하기 전에 현재 작업과 관련된 문서를 확인하고, 필요한 문서만 읽어야 합니다.

문서에 작성되지 않은 규칙이나 설계 내용을 임의로 확정하지 않습니다.

| `Rules/DOD_Rules.md` | DOD 설계 및 데이터 처리 규칙 | 데이터 구조 및 DOD 시스템 설계 |

설계 원칙은 먼저 작성하고, 실제 시스템 구조는 구현과 검증에 맞춰 갱신합니다.

## 5. 문서 참조 원칙

1. 작업 시작 시 `AGENTS.md`를 먼저 확인합니다.
2. 현재 작업과 관련된 문서만 추가로 읽습니다.
3. 설계안을 작성할 때는 `Architecture/Decisions.md`를 항상 먼저 읽습니다.
4. `Decisions.md`에 확정된 결정은 사용자가 변경을 요청하기 전에는 다시 논의하지 않습니다.
5. 기존 코드 수정 시 관련 Architecture와 GameDesign도 확인합니다.
6. 문서와 실제 코드가 다르면 임의로 판단하지 말고 실제 구현을 확인합니다.
7. 아직 작성되지 않은 문서는 내용을 추측하지 않습니다.
8. 새로운 규칙이나 설계가 확정되면 적절한 문서에 반영합니다.

## 6. 문서 작성 상태

현재 문서 구조는 작성 예정 항목을 포함합니다.

실제 파일이 생성되기 전까지는 해당 문서의 규칙이나 내용이 확정된 것으로 취급하지 않습니다.
